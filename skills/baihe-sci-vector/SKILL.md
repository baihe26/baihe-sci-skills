# baihe-sci-vector · 可编辑矢量生产


先区分两类任务：源PNG/SVG要求忠实重建，或已批准SceneGraph要求按图施工。前者先看源图，逐项记录可见文字/对象/关系及看不清处，不补隐藏结构；后者不重新设计或改变科学含义。科研照片不矢量化伪造成实验结果。

入口为 `baihe-sci.cmd --module vector --scene <SceneGraph>`；可加 `--target ppt`，重建加 `--source-image <源图>`。原科学绑定与来源需随任务记录。先用doctor核实配置的bridge、原生helper和设计合同；缺依赖安全交接，不扁平化冒充可编辑。

简单矩形、椭圆、路径、文字和关系按目标平台支持范围执行。复杂asset、clip、遮挡和专用实验路线保留原生产入口及PARTIAL状态。实际能力以原合同为准。

生产前读取同目录FigureSpec、ConstructionPlan、scientific_binding并核对来源与场景。输出逐元素处理清单。PPT中仅“两个端点均精确位于唯一矩形边中点的直线，可含沿线单调控制点”使用原生连接器，绑定语义组内矩形，可定向解析嵌套组；其他关系保留自由路径。移动/缩放跟随、解组再分组和重开证据只覆盖该矩形场景；不宣称所有曲线或原生分组都自动跟随。科研照片保留像素，编辑级别只能是移动/缩放/替换；不能计为原生图元或把整张原图分裁后宣称重建完成。

Illustrator导入会把下划线改成空格，须通过唯一性检查恢复语义ID并写native note，保留科学关系和来源哈希；逻辑layer_id记在note不等于建立独立原生图层。SVG使用pt物理尺寸与独立viewBox。递归审计嵌套路径，避免漏掉虚线子组；同级顺序从父集合读取。

只操作本次创建/打开且未被他人打开的文档，临时警告设置必须恢复。保存新AI/SVG/PNG或原生PPTX后，用独立客户端重开，实际选中、改字、改色、移动语义组并维护相关端点，修改局部关系后核对无关对象与科学身份。测试修改另存probe，不改最终图和源数据。

无位图、path数多、文件能打开都不单独证明对象可编辑。像素差、原生读回精度与视觉接受分开记录；微小差异不能改称零差。已知简单自制图的非盲测试不能外推陌生复杂图泛化。

0.3可显式选择`--target ppt --backend portable`，通过python-pptx生成受支持的简单原生场景及保留图片，不要求Office或私有引擎；默认后端不变。源PNG/JPEG按retained_assets记录原图坐标、SHA和显示bbox，嵌入原文件字节并原生裁剪，不拉伸。reconstruction_map声明必需原生区域及不确定项；同源裁图联合覆盖或遮住必需输出不能通过。未知字不猜，单列待核对，产物仍待审。

0.4在默认PPT施工和可选后端中把来源/证据/主张关联到真实对象位置；可选后端写入与Studio共用的标准Tags，并可用`--scene-deck`组成已批准的同尺寸多页图件。生成/库重载与Office实际打开/编辑/重开/视觉仍分别验收；复杂曲线、媒体与内容驱动汇报保留原路线。需要来源链、多页与引用操作时读`文档/证据与引用操作.md`，其他操作读`文档/可选后端与任务操作.md`。
