# baihe-sci-vector · 可编辑矢量生产

0.6可把关键文字、颜色、对象类型、连接目标、最小字号和实际编辑动作写入`delivery_requirements.json`。保存后的PPTX按目标回读；edit_action仍待真实原生操作，不能用文件解析充当编辑验收。保留位图可声明允许/禁止内容和外围原生对象，声明本身不等于视觉验证。按需读`文档/0.6升级与验收.md`。


先区分三类任务：源PNG/SVG的忠实重建、已批准SceneGraph的按图施工、沿作者现有AI/PPT父本的局部修订。重建先看源图，记录可见文字/对象/关系及看不清处，不补隐藏结构；施工不擅自改科学含义；修订先找当前原生对象和人工差异，保留不受影响的分组、路径、裁图和标签。不要导成PNG再套AI壳子。科研照片不矢量化伪造成实验结果。

**现有PPT只改文字、字体、字号或位置时，直接用`--edit-ppt <局部请求.json> --out <新目录>`。** `ppt_local_patch.inspect_ppt`可读取实际页码、原生shape_id、对象哈希和run。请求绑定当前PPT哈希，只选要改的对象；其余页面、备注、媒体、嵌入工程按原包字节保留。单run修改保留原样式，复杂混排逐run指定，不能压平公式。无需新建FigureSpec或科学三sidecar，也无需读完全部模块文档。COM局部编辑仍保留，复杂原生效果用其合适路线。接口例子在`文档/示意图与矢量改良.md`第1节。

`font_name`对所选run的拉丁、东亚、复杂文字三类字体共同生效；仅改中文或西文字体时分别用`font_east_asian`或`font_latin`，还可用`font_complex_script`。不要把只改了a:latin当成中文字体已修改；混排保持逐run范围，原生读回字体域与实际导出后再确认效果。

入口为 `baihe-sci.cmd --module vector --scene <SceneGraph>`；可加 `--target ppt`，重建加 `--source-image <源图>`。原科学绑定与来源需随任务记录。先用doctor核实配置的bridge、原生helper和设计合同；缺依赖安全交接，不扁平化冒充可编辑。

先用后端能力检查选择路线，再施工。SVG/Illustrator适配支持原有路径和层级，并传递线性/径向渐变、透明及关系线宽；portable PPT支持原生矩形、椭圆、文字、折线，以及绝对M/L/C/Q/Z贝塞尔路径、渐变和透明。其它路径命令、复杂asset/clip使用能力足够的现有原生路线。能力检查给具体缺项与替代路线，不自动简化或整图栅格化。复杂原生效果仍需实际保存重开和视觉核验，不能把写进XML当成审美验收。

按SceneGraph施工前读取同目录FigureSpec、ConstructionPlan、scientific_binding并核对来源与场景；这项要求不适用于已存在PPT的简单局部编辑。新施工输出逐元素处理清单。PPT中仅“两个端点均精确位于唯一矩形边中点的直线，可含沿线单调控制点”使用原生连接器，绑定语义组内矩形，可定向解析嵌套组；其他关系保留自由路径。移动/缩放跟随、解组再分组和重开证据只覆盖该矩形场景；不宣称所有曲线或原生分组都自动跟随。科研照片保留像素，编辑级别只能是移动/缩放/替换；不能计为原生图元或把整张原图分裁后宣称重建完成。

Illustrator导入会把下划线改成空格，须通过唯一性检查恢复语义ID并写native note，保留科学关系和来源哈希；逻辑layer_id记在note不等于建立独立原生图层。SVG使用pt物理尺寸与独立viewBox。递归审计嵌套路径，避免漏掉虚线子组；同级顺序从父集合读取。

只操作本次创建/打开且未被他人打开的文档，临时警告设置必须恢复。保存新AI/SVG/PNG或原生PPTX后，用独立客户端重开，实际选中、改字、改色、移动语义组并维护相关端点，修改局部关系后核对无关对象与科学身份。测试修改另存probe，不改最终图和源数据。

无位图、path数多、文件能打开都不单独证明对象可编辑。像素差、原生读回精度与视觉接受分开记录；微小差异不能改称零差。已知简单自制图的非盲测试不能外推陌生复杂图泛化。

按用户实际动作验收：改标签、改图例、挪标尺、改箭头、移材料组、调纤维曲线和渐变。源数据曲线在对应Origin工程中可改，照片仅可移动/缩放/替换，两者不能混称。沿现有PPT局部改字/移动/颜色时复用现有`ppt_adapter.local_edit`及人工冲突保护；高级AI局部编辑交原生桥接和已有工程，不能先重建整图。受支持SceneGraph显示修订可使用`refinement.revise`，修改后的端点仍要核对实体及最终图面。

显微图继承的是作者选中页的实际显示：原媒体、裁剪、镜像、旋转、亮度/对比度、标尺与箭头一起核对。保留仪器原像素和显示处理来源；不能只拿media目录图片代替已处理的显示，也不能生成填补实验结构。整体等比放大不自动使标尺错误，须从原始标定、裁剪及当前缩放链核实。

文字图层和原生上下标、旋转轴题、希腊字母、减号必须在最终软件中可读；检查照片盖字母、白底文本框、边界裁剪、渐变方向和连接端点。字库、字号层级和具体尺寸取当前任务/作者要求，不能把一张图的数值变为全项目规定。

修订总是另存，不丢来源和科学sidecar。新发现继续纳入修复；不因固定轮数结束，也不把审阅报告当问题已解决。接口及明确未覆盖项见`文档/示意图与矢量改良.md`。

0.3可显式选择`--target ppt --backend portable`，通过python-pptx生成受支持的简单原生场景及保留图片，不要求Office或私有引擎；默认后端不变。源PNG/JPEG按retained_assets记录原图坐标、SHA和显示bbox，嵌入原文件字节并原生裁剪，不拉伸。reconstruction_map声明必需原生区域及不确定项；同源裁图联合覆盖或遮住必需输出不能通过。未知字不猜，单列待核对，产物仍待审。

0.4在默认PPT施工和可选后端中把来源/证据/主张关联到真实对象位置；可选后端写入与Studio共用的标准Tags，并可用`--scene-deck`组成已批准的同尺寸多页图件。生成/库重载与Office实际打开/编辑/重开/视觉仍分别验收；复杂曲线、媒体与内容驱动汇报保留原路线。需要来源链、多页与引用操作时读`文档/证据与引用操作.md`，其他操作读`文档/可选后端与任务操作.md`。


0.5公开仓库已含配套源码。首次环境准备读取根目录“文档/0.5公开配套与自动安装.md”，使用“安装与检查.cmd”自动准备D盘独立Python与锁定依赖；不要沿用“私有引擎未提供”的旧结论。具体任务仍用“baihe-sci.cmd”与本机配置；商业软件、版本门禁、科学合同与逐模块原生验收保持原边界。
