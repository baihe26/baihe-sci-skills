# 白河组会文献专题汇报

适用于围绕当前科研问题组织一场能直接上台的文献专题汇报。优先使用用户确认的近期汇报稿或本次指定的样式参考。[成品参照与难点页](references/成品参照与难点页.md)给出通用页型和难点页讲法。

## 完整任务的成品

| 成品 | 交付标准 |
|---|---|
| **正式汇报 PPTX** | 可编辑、可投影，内容围绕当前课题问题。用清楚的原图和结论标题讲证据，保留需要现场读到的组别、对照和统计信息。默认清空 PPT 下方备注区。需放映 PDF 时，从最终版导出。 |
| **标记讲解版 PPTX** | 在最终正式 PPT 的真实页面上加醒目的编号、箭头或短提示，标出先看哪里、先比较谁、在哪收口。标记与讲解用“你先指……”“你可以这样说……”的排练口吻。标注位置避开原图数据、题目和文字。 |
| **逐页讲稿 DOCX** | 对着最终放映顺序可直接讲，每页有相同的页码和标题。用口语交代这一页要回答什么、怎么读图、讲到哪里和为什么接下一页。复杂页标出必讲与可跳细节，必要时补核心英文缩写或原图标签的中文说法。 |
| **关键难点页讲法** | 默认做进讲解版，并在讲稿同页呼应。选最容易讲错或卡住的页，逐个给出指图顺序、常见误读、可直接说的一两句和过渡。需要单独排练时再附一张简表或提词卡。 |

完整专题默认把前三项做齐，并提供难点页指导。若用户只要大纲、改一页或只补讲稿，就完成那一项。PDF、备用页和文献包按本次使用场景决定。

## 从本地材料到台上内容

- **先弄清这场报告要回答什么。** 根据用户给的课题阶段、汇报时间、听众和已有稿取舍。多个课题可围绕相通的问题串联，同时让听众看得出每项证据和下一步属于哪个课题。介绍必要的对象和术语，再讲这个选择为什么重要。
- **从已有材料挑证据。** 优先看现成提取、文献索引、图版和正式稿，回到入选论文的原图、完整图注、对应结果和影响读法的方法补充。能回答问题的论文进主线，其余按需求放备选。记录实际读到的范围，把题录、关键词命中和原文核对区分开。
- **一页讲清一个问题。** 引入论文时可沿用左侧题录和简短中文题名、右侧真实首页或期刊文章页的做法。结果页给原图和定量足够空间，标题点出比较或发现，图旁只放现场读图所需的解释。保留决定性对照、分图字母、轴、单位、图例、比例尺和显著性标记。
- **证据跟着结论走。** 保留图版来源定位。用论文本身能支持的动词，核清比较对象、时间点、分母、统计和关键阴性结果。稿内明确论文结果、课题已有事实和当前设想。缺少原件、图或事实时写具体待核项，用可识别的占位；情况不清楚时说明核对到的研究背景和来源。
- **以现场可用为准。** 以图清楚、标题明白、现场易读为目标。白底、深蓝标题、微软雅黑和轻量章节导航是可用起点。本次有更合适的参考、章节安排或视觉选择时，按实际内容调整。用简短总结分别说明近期要回答的问题和远期设想。

内容取舍、读取工具、排版方式、页数和是否先试排都随材料调整。需要判断投影效果时，可先看一页最密的图、一页文献引入和一处章节转场。用户要求直接完成时，自行解决可逆的制作选择。

## 交付前检查

- 对照最终 PPT 页序，把讲解版标记和讲稿标题同步到相同页。讲解版若只覆盖重点页，保留正式稿原页码。用户人工增删或重排后，用新页序重排对应材料。
- 用目标使用环境中的文档和演示工具查看实际效果，重点找正文溢出、图注不可读、标记盖住数据、字体替换和截图错位。确认正式稿备注符合要求。只有替代渲染时，说明能确认的范围。
- 新文件放在用户指定的位置或项目的交付子目录。保留原论文、原始数据和人工定稿。敏感材料在本地处理。提供一个交付入口，列出成品与确实影响使用的待核项。
