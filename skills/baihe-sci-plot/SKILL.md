# baihe-sci-plot · 科研数据图

先继承当前人工父本及已确认的数据选择，核对本轮要改的对象和最终用途。数据图、实验照片和机制示意分别处理。新入口支持真实表接入与已有 Origin 图局部修订；旧合成 Phase2C 基线和现有 EditaPlot 模板仍可直接使用。操作说明见仓库 `文档/数据图改良与验证.md`。


用于数值数据图。按本次动作核对所需事实：重算统计需要实验单位、独立/配对/纵向设计、n、误差类型及分母；只移动已核对标签不要求补造无关 n。不能从曲线相似、文件名或总行数推定实验身份或统计结论。

定位baihe-sci仓库与本机配置，只加载绘图依赖。复用已安装的绘图工位/Phase2C及EditaPlot，不替换vendor补丁。具体模板按其原合同执行。独立分类连续终点同时考虑“柱+独立点+已批准误差”与“独立点+汇总/误差”；选择由数据和用户目的决定。

旧入口 `baihe-sci.cmd --module plot --bundle <批准合成合同目录>` 保持原基线。真实任务用 `--plot-task <任务记录.json> --out <新目录>` 核对；加 `--execute-plot` 后沿现有引擎生成原生表图，或对已有 OPJU 另存副本实施支持的局部修改。宿主从当前对话和文件自动整理记录，不把手写合同当用户前置任务。未封装的模板/编辑动作交给准确的现成原生入口，并继续完成所授权任务，不能假称已经生产。

每条曲线追到文件、工作表/列、有效范围、组别与转换。核对源数组和实际使用数组，而不只数点；已有完整数据时不得用少量图片读点冒充原曲线。缺失段保留，显示抽稀须声明并保留完整原生源及关键窄峰。重新分箱、归一化、偏移、单位换算和能标转换分别说明。仪器导出、传阅资料和已发表文档各有适用范围：冲突先核同一对象及显示变换，不机械认定任何一个永远正确。

连续稠密谱默认无采样点符号；离散实测曲线按需要显示点；柱图可直接用类别轴；直方图保留经确认分箱；线型、点形及曲线选择由数据和图的用途决定。图例线、点、颜色与曲线一致，线样居中文字中线，不能像下划线。就近组名不要放在两条谱中间。峰标保留来源精度与数据锚，指示线留间隙；是否使用引线以该图当前要求为准。

样品身份、配方比例、处理时间和分峰分量采用不同视觉角色。有授权可一致重配色；不能改荧光/元素通道含义。名称可使用有原名映射的清楚显示名，不由缩写猜组成。全同材料但比较不同条件时可用相关色/线型，不能机械全用一个颜色。

物理字号、线宽、图层和长宽比按最终阅读尺寸、信号密度及当前作者/期刊设置，模板的 26/24/5 pt 等只属旧大画幅默认。不得为了紧凑压扁曲线或减小到不可读。适当留图区可避开照片遮挡，但不能补造零点、误差棒、显著性或改变峰形。XPS/俄歇保持源能标、展示能标及换算参数；不能只把动能标题改成结合能。科学错误说明先排除单位、偏移、归一化、标尺缩放等合理解释。

论文图和汇报显示副本按实际用途区分，来源对照版若承载同一正式图，应保留相同物理比例和当前内容。显示副本可调整字号、图例位置和显示留白，原值、n、误差、单位、分母和绑定须等价。输出新 OPJU 和对应导出图；核对原生数值、实际编辑、独立进程重开及最终尺寸图面。图例仍挡数据、字母被盖、刻度缺失不能以“可编辑，用户以后挪”通过交付。原生生成、重开、视觉审查与作者采用分别报告。

Origin沿用原队列和owned session；未知结果对账后再决定。安装、兼容和历史验证边界读仓库 `文档/能力与验证范围.md`。本技能不以代码执行成功替代科学判断。

当前CLI自动记录输入/产物哈希和阶段。中断后用`--status --request-id <原ID>`检查，来源/产物改变或Journal未知时不重跑；显示修订不绕过原统计语义门禁。图像差异可用`--compare-images`产生离线报告，环境不相同不作为回归通过。


0.5公开仓库已含配套源码。首次环境准备读取根目录“文档/0.5公开配套与自动安装.md”，使用“安装与检查.cmd”自动准备D盘独立Python与锁定依赖；不要沿用“私有引擎未提供”的旧结论。具体任务仍用“baihe-sci.cmd”与本机配置；商业软件、版本门禁、科学合同与逐模块原生验收保持原边界。
