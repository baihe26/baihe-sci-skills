# baihe-sci-plot · 科研数据图


用于数值数据图。先核对实验单位、独立/配对/纵向设计、n、误差类型、分母、单位、数值X及源数据绑定；缺项标记待核对，不猜统计结论。

定位baihe-sci仓库与本机配置，只加载绘图依赖。复用已安装的绘图工位/Phase2C及EditaPlot，不替换vendor补丁。具体模板按其原合同执行。独立分类连续终点同时考虑“柱+独立点+已批准误差”与“独立点+汇总/误差”；选择由数据和用户目的决定。

入口为 `baihe-sci.cmd --module plot --bundle <批准合同目录>`。当前薄适配的自动渲染仅接受明确标记的合成合同。真实数据须使用已核对的项目适配与当前授权，不移除合成门禁冒充支持。其他模板安全交接原EditaPlot入口，不能因未封装而说旧能力失效。

论文图和汇报显示副本分开。显示副本允许调整字号/图例位置，但原值、n、误差、坐标、单位、分母和绑定必须等价；按实际插入宽度检查有效字号与可见性。输出新OPJU和导出图，核对原生数值、独立进程重开、实际编辑及整图/整页视觉。不要覆盖源工程。

Origin沿用原队列和owned session；未知结果对账后再决定。安装、兼容和历史验证边界读仓库 `文档/能力与验证范围.md`。本技能不以代码执行成功替代科学判断。

当前CLI自动记录输入/产物哈希和阶段。中断后用`--status --request-id <原ID>`检查，来源/产物改变或Journal未知时不重跑；显示修订不绕过原统计语义门禁。图像差异可用`--compare-images`产生离线报告，环境不相同不作为回归通过。
