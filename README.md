# baihe-sci skills

从科研数据图、科学图设计，到可编辑矢量与科研汇报的本地技能系列。

**当前版本：0.5.0。** 五个技能、共享工作台和脱敏后的配套引擎源码现已随仓库提供。Windows x64下载后运行“安装与检查.cmd”，自动准备独立Python和锁定依赖；无需另取私有引擎。Origin、Illustrator、PowerPoint及其商业许可仍需自行具备。生成、原生重开/编辑、视觉与科学接受分别验收。

|技能|用途|
|---|---|
|[`baihe-sci`](skills/baihe-sci/SKILL.md)|总入口，选择单模块或跨模块链路|
|[`baihe-sci-plot`](skills/baihe-sci-plot/SKILL.md)|科研数据语义、可编辑数据图、论文/汇报显示副本|
|[`baihe-sci-design`](skills/baihe-sci-design/SKILL.md)|科学内容理解、构型与机制设计、FigureSpec与施工交付|
|[`baihe-sci-vector`](skills/baihe-sci-vector/SKILL.md)|忠实重建或按批准设计生产，AI/PPT原生对象与局部编辑|
|[`baihe-sci-slides`](skills/baihe-sci-slides/SKILL.md)|科研汇报、原生文字、媒体完整性、稳定引用和局部修订|

## 开始使用

1. 完整下载并解压到Windows x64电脑的D盘新目录，至少保留1GB空间。
2. 双击根目录 **安装与检查.cmd**。没有Python时也可运行；下载、校验与依赖安装只在本目录进行，不升级系统环境。
3. 在Codex打开此目录，交给它根目录 **发给Codex使用.txt**，再说明具体任务。已有五个技能不必重复安装。
4. 日常入口为 baihe-sci.cmd；--doctor只检查文件与依赖。原生软件用合成材料、新输出目录分别验收。

详见[0.5公开配套与自动安装](文档/0.5公开配套与自动安装.md)。手动接入旧引擎仍支持[安装与配置](文档/安装与配置.md)；既有本机配置不会被安装程序覆盖。

技能目录可以在本地项目中直接读取；若按Codex的技能安装方式逐个安装，仍须保留本仓库并让宿主通过 `BAIHE_SCI_HOME` 或明确路径定位共享工作台。不要只复制SKILL.md后宣称原生引擎已安装。

## 跨电脑使用

从0.5开始，普通GitHub源码下载已包含公开配套。若仍提示“私有引擎缺失”，请先更新完整仓库并运行安装入口。旧个人迁移包只作个人保存，不原样公开；详见[另一台Windows电脑的完整路线](文档/另一台Windows电脑的完整路线.md)。
