# 多页引用合成例

该清单引用同仓库的两个自制合成场景，均非科研结果。明确选择可选后端后，可生成带稳定页ID/对象ID及逐页来源链的两页原生图件。

```text
baihe-sci.cmd --module vector --target ppt --backend portable --scene-deck 示例/多页引用/scene_deck.json --out 工作台/产物/我的合成多页检查
```

混合页仍有未知文字待核对，不算正式可用或作者接受。通过`--reference-index`读取保留图片的稳定引用；真实项目的替换图片与科学合同须由宿主另行核对。完整边界见仓库`文档/证据与引用操作.md`。
