# 发给其他项目指导对话的使用说明

以下文字可直接转发；详细能力与限制见[系列工具详细介绍](系列工具详细介绍.md)。本说明只介绍工具，不提供科研项目资料。

## 可直接粘贴的消息

我已有一套本地科研工具系列，名为 **baihe-sci skills**，公开入口：https://github.com/baihe26/baihe-sci-skills 。请阅读README及“文档/系列工具详细介绍.md”，将它作为本项目可调用的生产能力参考。

有五个技能：baihe-sci负责协调；baihe-sci-plot负责有来源和语义合同的数据图；baihe-sci-design负责科学构型/机制/流程与FigureSpec设计；baihe-sci-vector负责忠实重建或按批准设计生产可编辑AI/PPT对象；baihe-sci-slides负责科研汇报、显示可读性、稳定引用与局部修订。

请先理解本项目的研究逻辑、当前状态与权威来源，再判断是否需要其中一个或多个模块。优先复用已有可靠成果，只做有价值的增量。原始数据和旧成果只读，输出另存；保留UNKNOWN/HOLD/CONFLICT，不把一致性检查、好看的图或软件运行通过当作科学证据。

图件需区分真实实验图像、数值数据图与概念示意图。数据的实验单位、n、误差、单位和分母先核对；机制的事实、解释和假说分开。可编辑性按对象报告，照片可保留像素，不承诺复杂曲线全部自动跟随。

这套GitHub仓库是技能与薄适配层，本机完整引擎另配。若你是网页对话，你不能直接访问我的磁盘或桌面软件；请负责指导，并输出一条给桌面Codex执行的限定任务。若你能访问本机，先核实技能文件、配置与依赖，不把名称存在当成工具已连接。不要为介绍工具而全项目重新扫描、重算或重画。

先给我：①最值得用在哪一项具体任务；②复用哪些现有资产；③仍需确认的关键事实；④一条限定执行指令及验收条件。当前资料足够时直接推进已授权范围；不得擅自发布、上传科研资料或调用收费服务。

## 桌面任务返回格式

```text
项目标识：
本轮目标与科学问题：
允许读取的来源/版本（网页端用逻辑位置，桌面端补真实路径）：
已有可靠资产，必须保留：
已确认内容 / HOLD / CONFLICT / UNKNOWN：
拟用模块及原因：
允许的变动范围：
输出与可编辑要求：
验收：来源保护、数值/语义、原生保存重开、实际编辑、视觉、未决项。
本轮不做：
```

每个执行任务记录唯一请求ID与输入版本。结果未知时先对账；不要换一个名字盲目重放。指导对话建议不自动成为科学确认或作者接受。
