# 安装与配置

这是多技能仓库与本地薄适配，不是四个底层引擎的完整安装包。当前原生支持以Windows为验证平台，软件及许可需要自行具备。所有下载、缓存和输出放在用户指定且有空间的工作盘；不要自动迁移现有成果。

复制根目录配置示例为 `baihe-sci.local.json`。各路径可以绝对指定，或相对于配置文件目录解析；`null`表示未配置，不能当成已安装。也可用 `BAIHE_SCI_CONFIG` 指向仓库外的本机配置。`BAIHE_SCI_PYTHON`指定Windows启动入口的Python；配置内的Python字段指定模块子进程解释器，两者需要具备对应模块依赖。

|配置项|需要什么|
|---|---|
|plot_root|现有科研绘图工位，含phase2c、phase2c_1、figure_system和vendor EditaPlot|
|plot_python / origin_python|分别为绘图检查/原生Origin的兼容Python环境|
|designer_root|现有Scientific Visual Designer，含冻结的重放设计原语|
|designer_contract_root|现有合同包，含FigureSpec与SceneGraph schemas|
|vector_root|现有Illustrator生产工具，含bridge/illustrator_bridge.py|
|illustrator_helpers|原生导出与审计helper模块，需提供JS_HELPERS；不包含任何研究输入|
|studio_root|现有Live PowerPoint Studio，含03_POC/source及V03等配置|
|ppt_backend_root|本机已安装兼容的ppt-mcp后端源码|
|python|PPT/Illustrator适配调用的Python；默认当前解释器|
|desktop_locks|本机需要遵守的共享桌面锁文件列表|

`python 工作台/源码/workbench.py --help` 和 `--doctor` 不要求原生引擎已安装。生产前按模块检查依赖；不存在的文件会返回安全停止，不触发原生调用。依赖诊断不检查COM连通性或许可证，也不代表能在另一台机器完整生产。

仓库的 `requirements.txt` 只列辅助检查依赖；没有自动安装Office、Origin、Adobe、后端或私有引擎。按本机现有环境安装需要的依赖，避免升级共享环境。仓库不自动改全局Skill、PATH或注册表。

```text
baihe-sci.cmd --doctor
baihe-sci.cmd --catalog
baihe-sci.cmd "只作图" --module plot --bundle <批准合同目录>
baihe-sci.cmd "先只设计" --module designer --spec <FigureSpec> --plan <ConstructionPlan> --binding <科学绑定>
baihe-sci.cmd "按已批准SceneGraph生产" --module vector --scene <SceneGraph>
baihe-sci.cmd "按已批准SceneGraph生产" --module vector --target ppt --scene <SceneGraph>
baihe-sci.cmd "这些图已经确认，排成汇报" --module ppt --manifest <已核对manifest>
```

运行日志、共同台账、临时文件、输出与本机配置都应留在本地，被.gitignore排除。不要用已有输出目录；重复request-id和未知结果先查日志。缺少原科学合同/统计事实时由宿主核对，不根据文件名推理实验事实。
