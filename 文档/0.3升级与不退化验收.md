# 0.3升级与不退化验收

版本0.3.0，2026-10-16。基线为0.2.0的`9bf55c2`。这次把此前评估中值得采用、且能在现有原则下验证的部分做成可运行功能。默认Origin、冻结Designer、Illustrator和Live Studio引擎继续保留，未改其源码、评分或原有图型状态。

## 已落地的改进

|借鉴点|本次实际实现|守住的边界|
|---|---|---|
|先骨架后生产|统一`--preflight`；设计输入可单独检查科学骨架，SceneGraph检查科学合同、物理比例、父子关系和声明的布局约束|检查一致性，不代替科学理解和作者接受；不强迫简单任务重新设计|
|逐区域重建与裁图|retained_assets与reconstruction_map；原图像素坐标、SHA、纵横比、必需元素与编辑去向|PNG/JPEG原文件字节直接嵌入，原生裁剪；真实图片只承诺移动/缩放/替换；其他格式/复杂裁剪交回现有路线|
|防假编辑性|计算同源裁图联合覆盖；必需原生文字/箭头区域被裁图覆盖时拒绝，原生语义不能用图片输出替代|不靠“每块裁图小于98%”或形状数量过关；依赖宿主提供的真实区域地图，不冒充通用图像理解|
|未知文字不猜测|允许明确的omitted_pending_review；进入元素清单、生产前检查和待核对说明|可以生成待审草稿，不宣称全文字保留、正式可用或作者接受|
|证据链借鉴|可选evidence_map，将来源块、E证据、C主张及supports/limits/contradicts/mixed关系关联到现有FigureSpec|文字引文可核对，PDF页码/bbox仍是未独立核实的定位；不自动采纳，不替换Nature精读流程|
|布局约束借鉴|contains、disjoint、min_gap、aligned、min_font_pt与越界检查|只检查声明的约束，不自动移动对象或改变科学关系，也不把粗bbox检查当完整视觉验收|
|有上限的定向修订|`--revise`实际生成新修订，绑定整包/父SceneGraph/评审文件的哈希、finding与允许对象；默认最多两轮，问题须严格减少|仅允许填充/描边/线宽/字号；不改字、数值、主张、关系或真实图像；父版本与无关对象不变|
|阶段与恢复|当前CLI自动记录输入/输出交接与产物哈希；`--status`核对来源、产物、回执和Journal|人工改动变为冲突；未知写入不自动重试；不声称已迁移全部历史工具或拥有通用工作流引擎|
|可移植生产|可选python-pptx后端，简单原生图元、分组、矩形绑定连接器、自由路径与保留图片；独立环境安装入口|生成不需要Office或私有引擎；Office真实重开/渲染仍须另验。默认COM后端不变；Studio Tags未凭空生成|
|差异验收|环境绑定的PNG差异JSON与离线HTML，展示基线、候选、绝对差图|环境不匹配不宣称回归通过；像素、原生编辑性与科学正确性分验|

## 验证与修复

- 36项自动测试覆盖合法旧合同、科学变异负例、同源裁图联合覆盖、纵横比/像素来源、不确定字、证据映射、父版本/整包/人工冲突、定向修订、真实PPTX输出及状态恢复。
- 单独在新建的可选Python环境安装依赖并运行同一套检查；默认本机配置及既有Python环境未升级。缓存和新环境留在工作盘，不打包进GitHub。
- 默认PPT已知简单例重新生产、保存重开；与0.2原PPT在同一当前环境只读重开后的渲染完全一致。默认AI例重新生产并用独立客户端重开，合同检查通过。数据图仍使用批准合成合同回归，统计语义与真实数据门禁不移除。
- 可选后端的简单/混合例经过真实PowerPoint只读打开、渲染、重开；原生快照和各自重开像素一致。文本、改色、组移动/缩放和绑定端点通过原生编辑探针，原文件未修改。混合例保留一张原始字节图片，外部文字与连线为原生对象。
- 两种生成后端作了同合同的盲化只读视觉比较。发现可选后端继承Office主题投影后，显式禁用主题效果；修正版复核无新实质问题。不能仅凭结构测试通过就宣布视觉无退化。
- 修正版可选后端与默认后端仍有局部像素差，差异保留在报告里；不把它改称像素相同。它是可选路线，不替换默认后端。

历史失败与限制记录留在本地：包括初次连接器填充API不适用、原生队列繁忙安全停止、主题效果退化及修复。科学源/旧成果未用于这次合成测试；原有定向保护快照另行检查。安装与本机验证不证明另一台机器、其他操作系统或全部复杂图已经通过。

## 实际复用与未采用项

实际复用[python-pptx 1.0.2](https://github.com/scanny/python-pptx)（MIT，外部依赖，未修改/复制上游源码），调用其图元、分组、连接器、图片裁剪和保存读取接口；[官方形状文档](https://python-pptx.readthedocs.io/en/latest/api/shapes.html)的矩形连接点限制由本系列继续限定并做实际编辑检查。Pillow用于图像读入/差异和自制测试图，依赖遵循其自有许可。环境与依赖不随源码仓库再分发。

Norman、LiveFigure的方法只用于接口与验证思路参考，未复制无明确许可的引擎。Penrose的语义/约束分离、LangGraph的阶段/恢复、pytest-mpl的基线/差异报告被用于局部机制设计，未引入整套框架；现有任务不需要这些重依赖。PptxGenJS与另一套PPT服务未另起生产主链，避免重复维护。

没有做Norman宏重建、Norman同图同模型成本/质量排名、真实科研新实验/统计、陌生复杂图泛化评测、付费生成或整应用重启。保留它们的未验证状态，比无证据宣布“全面更强”更符合本系列原则。
