# 可选后端与任务操作

当前默认生产链照常配置和使用。下面的基础功能从0.3加入；0.4继续补充标准Tags、已批准多页图件和保存文件引用更新，详见[证据与引用操作](证据与引用操作.md)。选择`portable`才使用python-pptx，不自动切换现有任务。

## 无私有引擎的简单PPTX生成

已有Python 3.11+及`requirements-portable.txt`中的依赖即可；不要求Office、Adobe、Origin或冻结Designer。输入仍要有完整、已核对的科学合同，不是只给PNG便自动完成图像理解。

可选依赖固定为本次验证版本，避免安装时静默漂移；升级依赖需重跑受影响检查。

```text
python 安装可选后端.py --dry-run
python 安装可选后端.py
```

安装入口只创建新的隔离环境和`baihe-sci.portable.local.json`，不升级已有环境，不覆盖默认配置，不修改全局PATH/Skill/注册表。Windows下仓库、缓存和目标环境须在D盘；安装前检查可用空间。已有环境或可选配置时停止保留，避免静默覆盖。支持`--wheelhouse`使用已准备的本地依赖轮子；默认依赖需联网下载，均缓存在工作目录。

PowerShell中可以只为当前终端指定配置，然后运行仓库入口：

```powershell
$env:BAIHE_SCI_CONFIG = (Resolve-Path .\baihe-sci.portable.local.json).Path
.\工作台\可选环境\Scripts\python.exe .\工作台\源码\workbench.py --doctor
.\工作台\可选环境\Scripts\python.exe .\工作台\源码\workbench.py --module vector --target ppt --backend portable --scene .\示例\混合重建\IllustratorSceneGraph.json --out .\工作台\产物\我的新测试 --request-id 我的新测试
```

可选配置只配置可选Python，不能因此宣称默认四套本机引擎已安装。项目中已有完整本机配置时也可保留它，配置`portable_python`或沿用已有具备依赖的Python。可选生产交付PPTX、元素清单、生产前检查、验收记录及有需要时的待核对说明。

可选后端支持矩形、椭圆、文字、折线路径、分组、精确矩形边中点的绑定直线，以及显式保留的PNG/JPEG矩形裁图。复杂资产、自由曲线、复杂clip、媒体和多页正式汇报继续走原模块/后端。形状名称与description保留原身份记录；0.4另写入与Live Studio共用的原生Tags，支持声明范围内的保存文件引用更新。已批准同尺寸多页图件可用`--scene-deck`，不等于默认后端的全部内容设计、媒体或引用能力。

## 生产前检查与扩展合同

```text
baihe-sci.cmd --preflight --scene <SceneGraph> --out <新的检查目录>
baihe-sci.cmd --preflight --spec <FigureSpec> --plan <ConstructionPlan> --binding <scientific_binding> --out <新的骨架检查目录>
```

单独检查不会启动原生应用。SceneGraph同目录可选放置下列文件，实际例子见`示例/混合重建`：

|文件|宿主应填写的内容|
|---|---|
|retained_assets.json|原文件路径/哈希/像素尺寸；原图矩形坐标、图中bbox、保留理由、内容类型和实际编辑级别|
|reconstruction_map.json|每个必需源区域的去向、原生要求、精确可见文字、不确定项；复杂关系可用多个局部区域避免宽大bbox误判|
|layout_constraints.json|明确需要的包含、不相交、间隔、对齐和最终物理字号限制；不套统一审美阈值|
|evidence_map.json|来源块、页码/bbox定位、E证据、对应C主张和支持/限制/反驳/混合关系；作者决策单列|

来源像素区域及语义由宿主核对，程序不自动识别图片内容。科研图片不得拉伸；原文件字节保留，PPT的native crop只控制显示。原生语义区域被同源裁图联合覆盖会拒绝，不能用多个大裁图冒充完整重建。

不确定文字可明确`omitted_pending_review`，保持未决而不补猜；因此生成状态仍是待审，`release_ready=false`。PDF页码/bbox是定位输入，当前适配没有自动完成PDF精读或确认引文解释；文字文件的引文可以做字面核对。

## 有范围的显示修订

先由宿主或独立检查形成评审JSON，包含`artifact_scene_sha256`、`reviewer`与具体`findings`（每项有id和object_ids）。补丁JSON绑定：

```json
{
  "expected_parent_sha256": "当前SceneGraph文件哈希",
  "expected_pack_sha256": "生产前检查返回的input_fingerprint",
  "review": {"path": "review.json", "sha256": "评审文件哈希"},
  "finding_ids": ["F1"],
  "allowed_object_ids": ["AI_text_A"],
  "changes": [{"object_id": "AI_text_A", "fields": {"fill": "#263238"}}]
}
```

```text
baihe-sci.cmd --revise <补丁JSON> --scene <父SceneGraph> --out <新的修订目录>
```

允许填充、描边、线宽和文字字号（`font_size_px`）。修改文字、科学主张、数据或关系需要另外的科学修订，不能伪装成显示补丁。每轮另存整包修订与记录，原件保留；默认两轮，后续评审问题集合必须严格减少。新的修订仍须独立复核，没有自动视觉critic或自动作者批准。

## 状态与差异

```text
baihe-sci.cmd --status --request-id <原任务ID>
baihe-sci.cmd --compare-images --baseline <基线PNG> --candidate <候选PNG> --baseline-environment <基线环境JSON> --candidate-environment <候选环境JSON> --out <新的比较目录>
```

状态检查发现来源变化、产物变化或未确认写入时只报告冲突，不重放。当前CLI的输入/输出交接自动绑定文件哈希；旧任务没有产物哈希时明确报告证据不足，不补造历史回执。摘要中的input fingerprint是输入包指纹，不等于科学真实性。

环境JSON记录真实的`renderer`、`version`、`font_fingerprint`和`resolution_px`，不可为使检查通过而填写相同占位值。环境相容后报告精确像素差、差异框和离线HTML；环境不相容仍可查看图片，但不宣称回归通过。查看`查看差异.html`即可并排读图；科学方向、原生编辑性和人工接受仍分别核对。
